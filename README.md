## GitHub Pages Deployment

For this repository, GitHub Actions sets the Vite base path to `/altcoin-strategy-lab-demo/` during deployment.

Recommended GitHub Pages settings:

- Source: GitHub Actions
- Build command: `npm run build`
- Output folder: `dist`

This repository includes a GitHub Actions workflow at `.github/workflows/deploy.yml` when Pages deployment is enabled.

## Cloudflare Pages

Cloudflare Pages settings:

- Framework preset: Vite
- Build command: `npm run build`
